# MOBA Prototype

Прототип игры в жанре MOBA на Unity. Одна игровая сессия от старта до итогов: две команды, волны юнитов, управляемый герой со способностями, победа или поражение и статистика матча.

**Движок:** Unity 6000.0.29 (шаблон Universal 3D)

## Как запустить

1. Установите Unity **6000.0.29** через Unity Hub.
2. Склонируйте репозиторий и откройте папку проекта через **Unity Hub → Add → Add project from disk**.
3. Откройте сцену из папки `Assets/Scenes` и нажмите ▶ **Play**. Вкладку **Game** лучше поставить в формат **16:9**.

## Цель игры

Вы играете за **красных** (база слева внизу). Разрушьте **синюю базу** (справа вверху), не дав разрушить свою. Обе базы имеют по 500 HP.

Каждые 20 секунд с обеих баз выходят волны юнитов. Они идут по тропинке, сражаются друг с другом и атакуют вражескую базу. Ваш герой сильнее обычных юнитов и помогает склонить бой в вашу пользу.

## Управление

| Действие | Клавиша |
|---|---|
| Бежать в точку | ПКМ по земле |
| Атаковать врага или башню | ПКМ по цели |
| Остановиться | **S** |
| Приблизить и отдалить камеру | Колёсико мыши |
| Способность **Slam** | **Z** |
| Способность **Dash** | **X** |
| Способность **Rage** | **C** |

Если рядом со стоящим героем появляется враг, он атакует его сам.

## Способности героя

| Клавиша | Название | Что делает | Перезарядка |
|---|---|---|---|
| **Z** | Slam | Удар по площади (радиус 4), 40 урона всем врагам вокруг | 7 с |
| **X** | Dash | Рывок на 7 метров к курсору, останавливается у края карты | 5 с |
| **C** | Rage | На 5 секунд: урон ×1.6, скорость ×1.4, герой краснеет | 14 с |

Состояние перезарядки показано на панели внизу экрана.

## Механики

- **Герой:** 300 HP, при гибели возрождается у своей базы через 8 секунд.
- **Юниты:** 60 HP, 10 урона в секунду. Идут по маршруту, замечают врагов в радиусе 6, юниты в приоритете над башней.
- **Волны:** первая через 3 секунды, в ней 3 юнита. Каждые 3 волны размер растёт на 1, максимум 6.
- **Лечение у базы:** вокруг каждой базы зелёный круг (радиус 6). Свои юниты и герой внутри него восстанавливают 8% здоровья в секунду.
- **Конец матча:** при падении любой базы игра замедляется, затем останавливается и показывается экран итогов.

## Статистика матча

На экране итогов показываются результат (**VICTORY** или **DEFEAT**), время матча, число волн и для каждой команды: убито врагов, потеряно юнитов, нанесено урона. Кнопка **PLAY AGAIN** перезапускает матч. Во время игры вверху экрана виден таймер и счёт убийств.

## Структура проекта

Скрипты лежат в `Assets/Scripts`:

| Скрипт | Назначение |
|---|---|
| `Health` | Здоровье, команды, события урона и смерти |
| `HealthBar` | Полоска здоровья над объектами |
| `UnitAI` | Поведение юнитов: маршрут, поиск целей, атака |
| `WaveSpawner` | Спавн волн юнитов |
| `GameManager` | Ход матча, статистика, победа и поражение |
| `GameUI` | HUD и экран итогов |
| `HeroController` | Управление героем, автоатака, возрождение |
| `HeroAbilities` | Способности Z, X, C и панель перезарядок |
| `HealZone` | Лечение рядом с базой |
| `CameraFollow` | Камера, следящая за героем, с зумом |

Графика сделана из стандартных примитивов Unity (капсулы, цилиндры, сферы). Юниты, герой и базы устроены так, что внешний вид лежит в отдельном дочернем объекте, поэтому примитивы легко заменить моделями.

## Ресурсы

- Карта сгенерирована нейросетью.
- Все остальные объекты созданы средствами Unity.
